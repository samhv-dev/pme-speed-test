# Body speed test

A one-minute measurement page: it times a synthetic network of blood compartments, substances and chemistry in the browser, to see how large a simulated body can be on a phone, a tablet or a laptop and still run faster than real time.

It is not physiology and not part of any product. Open the page, tap "Run the test", keep the screen on, then copy the result text.

Page: https://samhv-dev.github.io/pme-speed-test/
